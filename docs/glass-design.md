# 웹 디자인: 실버·차콜 글라스

홈, 프로필, 블로그에 중립적인 색상과 얇은 반사광을 적용합니다. PDF 출력 페이지의 개별 스타일은 유지합니다.

- `styles/tokens/glass.css`: 라이트·다크의 배경, 본문 대비, 링크 색상, 유리 표면·테두리·그림자 정의. 기존 색상 토큰 뒤에서 웹의 의미별 색상을 재정의합니다.
- 큰 색 번짐과 네온 글자 그림자를 제거합니다. 홈은 유리 링, 내비게이션과 소개 카드는 반투명 표면으로 깊이를 표현합니다.
- 본문은 불투명한 글자와 넉넉한 행간을 유지합니다. 블러는 홈·내비게이션·프로필 소개·테마 버튼에 한정합니다.
- 모바일은 단일 열 구성을 사용하고 작은 화면에서는 내비게이션을 줄바꿈합니다.
- 키보드 포커스 윤곽선을 제공하며, 모션 감소 설정에서는 애니메이션과 전환 시간을 줄입니다.
- 배경 블러를 지원하지 않거나 투명도 감소를 선호하는 환경에서는 단색 표면을 사용합니다.

브라우저 확인 이미지: `output/playwright/` (Git 제외).
